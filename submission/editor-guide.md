# 모먼트 — 여러 사진·문구 편집기 (Vercel)

정적 HTML/CSS/JavaScript로 동작합니다. Supabase·서버·API 키·npm 설치가 필요 없습니다. `vercel.json`의 출력 폴더는 `dist`입니다.

## 이번 수정
- 기본 템플릿의 Dear, today / a little / moment. / MAKE / IT YOURS. / MOMENTS TO KEEP도 일반 문구입니다. 미리보기나 목록에서 선택해 내용·글꼴·크기·색·위치를 바꾸고 삭제할 수 있습니다.
- 예전 템플릿에서 보이던 고정 문구는 처음 불러올 때 한 번만 변환됩니다. 삭제한 문구는 다시 불러와도 재생성하지 않습니다.
- 비율 유지 체크박스와 자동 잠금 동작을 제거했습니다. 기존 저장본의 잠금 설정도 해제해 가져옵니다.

- 여러 PNG/JPEG 파일을 한 번에 선택하거나 나중에 추가할 수 있습니다. 기존 사진은 유지됩니다.
- 문구 추가 버튼으로 여러 문구를 만듭니다. 각 문구의 내용·글꼴·색·크기·위치를 독립적으로 편집합니다.
- 미리보기 또는 사진·문구 목록에서 선택합니다. 겹친 항목도 목록에서 선택할 수 있습니다. 문구는 사진보다 앞에, 새 사진은 이전 사진보다 앞에 표시됩니다.
- ‘삭제’ 버튼과 Delete 키는 선택한 사진 또는 문구만 지웁니다. 입력칸에서 Delete는 글자 편집에 사용합니다. 되돌리기로 복구할 수 있습니다.
- 글꼴 10종: 템플릿의 Georgia 기울임, 굵은 산세리프, 보통 산세리프 및  맑은 고딕, 바탕, 궁서, 굴림, 돋움, Georgia, Consolas. 기기에 설치된 글꼴을 사용하며 없는 글꼴은 대체됩니다. Windows의 기본 한글 글꼴을 중심으로 구성했습니다.
- 캔버스 색상 및 쉐이딩(그라데이션)의 색상·강도·방향을 조절합니다. ‘빈 캔버스’ 기본 템플릿으로 자유롭게 꾸밀 수 있습니다.
- 배경은 사진보다 먼저 그립니다. 사진 자체에는 색상·쉐이딩 필터를 적용하지 않습니다. ‘사진을 캔버스로 사용’ 또는 ‘캔버스 삭제’에서는 배경 효과를 아예 그리지 않고 설정도 비활성화합니다. 투명 PNG를 일반 캔버스 위에 놓으면 투명 부분을 통해 배경이 보일 수 있습니다.
- ‘사진을 캔버스로 사용’은 지정한 사진 ID를 유지합니다. 다른 항목을 선택해도 저장 영역이 바뀌지 않습니다. 지정 사진을 삭제하면 일반 캔버스로 돌아갑니다.
- 일반 캔버스의 비율 변경은 사진 좌표·크기를 보존합니다. 사진 캔버스에서는 지정 사진, 캔버스 삭제 상태에서는 선택 사진(문구 선택 시 첫 사진)의 비율을 바꿉니다. 비율 유지 체크박스는 제거했습니다. 꼭짓점도 자유 비율로 크기를 바꾸고, 사진에 비율 버튼을 적용하면 크기를 늘이거나 줄입니다. 별도 자르기 탭은 유지됩니다.
- 캔버스 밖 사진은 반투명하게 남아 드래그할 수 있습니다. 캔버스 삭제 후 한 장의 자유 이동 동작을 유지하며 여러 장은 모든 사진을 포함하는 영역으로 저장합니다.
- ‘선택 사진 저장’은 해당 사진만, ‘이미지 저장’은 전체 작업을 저장합니다. PNG는 투명도 유지, JPEG의 투명 영역은 흰색입니다. 캔버스 밖 반투명 표시는 저장되지 않습니다.
- 템플릿과 JSON에 모든 사진·문구·글꼴·배경 설정을 저장합니다. 이전 단일 사진/문구 형식도 불러올 수 있습니다. 템플릿은 이 브라우저의 IndexedDB에 저장되므로 다른 기기나 주소로 옮길 때 JSON을 사용하세요.

## 실행·배포
압축을 푼 폴더의 `vercel.json`, `dist`, `tests` 등을 GitHub 저장소 최상위에 넣습니다. 기존 Vercel 연결 저장소라면 변경 사항을 커밋·푸시해 재배포합니다. 프레임워크는 Other, 출력 폴더는 dist입니다. 이 ZIP은 배포 가능한 소스이며 실제 재배포는 수행하지 않았습니다.

로컬 확인: 이 폴더에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000/dist/`를 엽니다. HTML을 파일 탐색기에서 직접 열면 ES 모듈을 불러오지 못할 수 있습니다.

## 검증
- `node tests/multi-editor-check.mjs`: 현재 앱의 이벤트 핸들러와 렌더러를 실행하는 자동 검사 23개. DOM·Canvas·IndexedDB는 대역을 사용합니다.
- `node tests/check.mjs`: 기존 순수 편집 로직 검사.
- 현재 결과: `dist/multi-editor-results.json`.
- 이전 버전 검사 결과는 `evidence` 및 일부 기존 JSON에 보존되어 있으며 최신판의 실제 브라우저 통과 증거가 아닙니다.
- 실제 브라우저 드래그, 글꼴, PNG/JPEG 출력 픽셀 대조, 새로고침 뒤 IndexedDB 유지, 공개 URL의 시크릿 무로그인 접속은 별도 확인이 필요합니다.

## 과제 조건
첨부된 원문은 `evidence/assignment.txt`입니다. 다중 항목·폰트·배경 기능을 금지하는 조항은 없습니다. 다만 기능 추가만으로 과제 전체 통과가 확정되는 것은 아닙니다. 제출 전 C11–C13 실제 화면/출력 대조, C14–C15 극단 입력 12건과 수정 전후 증거, C21 재접속 유지, C01 공개 접근 및 고정 GitHub 커밋 URL을 확인하세요. `dist/submission.html`에 확인 방법을 정리했습니다.

사용량 보호: 사진/문구 각각 100개, 입력 사진 한 장 20MB·4천만 화소·한 변 12000px 이하. 업로드 이미지는 긴 변 2400px 이내로 재인코딩하며 원본 위치 메타데이터를 복사하지 않습니다. 사진 편집 크기는 캔버스 경계로 제한하지 않으며 저장 시 4천만 픽셀 한도를 확인합니다. 잘못된 일괄 업로드나 JSON은 기존 작업을 지우지 않습니다.
