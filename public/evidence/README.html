이전 버전의 편집기 검사 기록입니다. 이미지 편집 엔진은 유지했으며, 이번 Vercel·Supabase 저장 API의 별도 검사 결과는 배포 묶음의 TEST-RESULTS.md에 기록합니다. 새 배포 환경의 실서비스 연결 검사는 설정 후 진행해야 합니다.

이 페이지는 과제 T03의 증거 보관용입니다. 기록된 통과와 아직 확인하지 못한 항목을 구분했습니다.

대표 결함 전후

E12: 한글 한 글자 + 줄바꿈 1,999개를 1:1 카드에 입력. 수정 전 최소 1px 제한으로 문구 영역이 2,700px가 되어 카드 밖으로 넘쳤습니다(FAIL). 수정 후 필요한 경우 1px 미만까지 비례 축소해 높이 972px로 제한했습니다(PASS). 입력은 그대로 유지됩니다. 극단적으로 많은 줄은 매우 작게 보이므로 문구를 줄이는 것이 좋습니다.

화면비와 내려받기

1:1(1080×1080), 4:5(1080×1350), 9:16(1080×1920): 실제 미리보기 캔버스가 다운로드의 원본입니다. 자동 검사에서 각 PNG를 다시 열고 픽셀 배열 전체가 동일함을 확인했습니다. 브라우저 편집기에서 실제 파일 내려받기도 실행했습니다.

브라우저 기능 검사

  • 첫 화면의 이미지·문구 도구 확인.
  • PNG와 JPEG 업로드 후 이미지 적용 및 메타데이터 제거 안내 확인.
  • 지원하지 않는 텍스트 파일 거부 사유 표시 및 기존 이미지 유지 확인.
  • 내 템플릿 3개 생성 → 첫 템플릿 불러오기·문구 수정 → 세 번째 삭제 → 새로고침 후 2개 유지 및 수정 문구 복원 확인.
  • 정상 JSON의 템플릿 3개 추가(2→5), 손상 JSON과 필수 항목 누락 JSON은 오류 표시와 5개 목록 유지 확인.

WebMCP는 검사 브라우저에서 지원하지 않아 실행 검증하지 못했습니다. 일반 편집 기능에는 필요하지 않습니다.

짧은 확인 방법

① 어디로 가나요: 공개 편집기 첫 화면.
② 무엇을 하나요: 1) PNG 또는 JPEG를 불러옵니다. 2) 문구·위치·크기·색과 비율을 바꿉니다. 3) 이미지를 내려받습니다.
③ 무엇이 보이면 통과인가요: 미리보기와 저장 이미지의 잘림·문구 위치·줄바꿈이 같습니다.
④ 안 될 때 무엇이 보이나요: 오류 이유가 표시되고 기존 작업이 유지됩니다.
