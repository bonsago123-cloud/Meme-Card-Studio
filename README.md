# 모먼트 — Vercel 이미지 편집기 수정판

## Vercel 배포
ZIP을 풀고 내용 전체를 하나의 GitHub 저장소 최상위에 올린 뒤 Vercel에서 Import합니다.
- Framework: Other
- Root Directory: vercel.json이 있는 폴더
- Output Directory: dist
- Build/Install Command: 없음
- Supabase/API 키/환경변수: 필요 없음
설정은 vercel.json에 포함되어 있습니다. 이 작업에서 실제 Vercel 재배포는 하지 않았습니다.

## 현재 비율 동작
| 상태 | 비율 버튼 동작 |
|---|---|
| 일반 캔버스 표시 | 캔버스만 1:1 / 4:5 / 9:16으로 변경. 사진의 위치·크기·자른 영역은 그대로 유지 |
| 사진을 캔버스로 사용 | 사진에 비율 적용. 비율 유지 체크 시 중앙 자르기, 해제 시 늘리기 |
| 캔버스 삭제 | 사진에 비율 적용. 비율 유지 체크 시 중앙 자르기, 해제 시 늘리기 |

‘사진에 적용’은 제거했습니다. 이전 JSON에 해당 값이 있어도 비율 변경을 막지 않습니다.
일반 캔버스의 좌표 원점은 항상 고정되므로, 사진을 밖으로 옮긴 다음 비율을 바꿔도 사진이 튀거나 변형되지 않습니다.
비율 버튼은 캔버스/출력 영역 전체를 화면에 맞춥니다. ‘작업 전체 보기’는 캔버스와 밖에 있는 사진까지 함께 보여줍니다.
캔버스 밖 사진은 연하게 표시되며 저장되지 않습니다. 다시 잡고 안으로 옮길 수 있습니다.

## 기타 유지 기능
- PNG/JPEG 업로드·저장, 지원하지 않는 파일 오류 시 기존 작업 유지
- 테두리/꼭짓점 크기 변경, 자르기, 원본 복구, 되돌리기
- 캔버스 삭제 체크 및 복원, 사진 삭제 버튼·Delete 키 (입력란 제외)
- 문구 크기·색·위치 변경, 직접 드래그
- 템플릿 CRUD·새로고침 유지(IndexedDB), JSON 백업/복원
- 캔버스 없는 사진은 고정 미리보기 경계에 잘리지 않도록 별도 사진 요소 사용
- 보기 배율은 사진 데이터 크기와 독립

템플릿은 같은 사이트 주소·같은 브라우저에 저장됩니다. 주소 변경 시 JSON으로 옮기세요.
사진의 편집 크기에는 10000px 상한이 없습니다. 내보내기는 기존 4천만 화소 제한을 유지합니다.

## 수정 및 확인
- 비율 변경 시 사진을 중심으로 화면을 맞추던 버그 → 출력 캔버스 기준으로 수정
- 예전 적용 체크값이 변경을 차단하던 경로 → 제거
- 캔버스 밖 사진의 원치 않는 변형 → 일반 캔버스에서는 사진 데이터를 변경하지 않음
- 템플릿 불러오기/되돌리기 중 이미지 읽기 경쟁 → 요청 순서 확인
- 큰 이미지 저장 전 크기 검증, 편집 모드 변경 시 이전 드래그 종료

현재 검사 실행:
```
node tests/check.mjs
node tests/editor-check.mjs
node tests/render-check.mjs
```
기본 문구/JSON/기하 검사 13건, 편집 상태 회귀 검사 19건, 실제 렌더·화면 맞춤 함수를 대역으로 실행한 검사 4건.
모두 통과했습니다. 테스트는 실제 브라우저 클릭/스크린샷/픽셀 비교를 대신하지 않습니다.
이전 버전의 검사·결과는 evidence/previous-tests 및 기존 결과 JSON에 보관되어 있으며 이전 동작 기록입니다.

## 과제 제출
기능 추가 자체는 금지되어 있지 않습니다. 전체 과제 통과로 확정한 것은 아닙니다.
세 비율별 실제 미리보기·다운로드 대조, 템플릿 CRUD 후 재접속, 시크릿 공개 URL 접속, GitHub full commit URL, 학생 판단 기록 확인이 필요합니다.
dist/submission.html 및 dist/assignment-review.md에 확인 방법이 있습니다.

## 로컬 실행
`python -m http.server 8000 --directory dist` 후 http://localhost:8000
HTML 파일을 더블클릭하는 file:// 방식은 JavaScript 모듈을 차단할 수 있습니다.

## 캔버스 밖 사진 표시 수정
캔버스가 켜진 상태에서 밖으로 나간 사진 부분은 별도 사진 요소에 30% 불투명도로 표시합니다. 고정 미리보기 비트맵 밖으로 나가도 해당 요소를 드래그하여 다시 옮길 수 있습니다. 캔버스 안쪽은 기존 선명도로 표시하며, 바깥 표시용 요소는 저장 파일에 포함하지 않습니다.
캔버스 삭제 상태의 그림·이동 경로는 변경하지 않았습니다. 화면/편집 패널에 가려 사진을 찾기 어려운 경우 ‘작업 전체 보기’를 사용하세요.
이 수정은 코드와 모의 렌더 검증을 했으며 실제 브라우저 확인 및 Vercel 배포는 아직 하지 않았습니다.
